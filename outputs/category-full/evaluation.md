# Проверка полного словаря категорий

Проверены все 518 компании из `companies.xlsx` в исходном порядке. Товарные строки есть у 139 компаний; у 379 их нет. Внешние API и LLM не использовались.

## Состав словаря

- 2750 записей: по одной на каждое уникальное название `category-normal`.
- 394 категорий с явными синонимами, сокращениями или контекстными фразами.
- 30 категорий используют примеры из скобок справочника.
- 2246 категорий пока имеют только совпадение с названием.
- 80 неоднозначных категорий отключены до уточнения родительского пути.
- Всего 3418 фраз. Это не полный набор всех возможных смысловых синонимов.

## Полный прогон

| Показатель | До изменений | После изменений |
|---|---:|---:|
| Компаний в выборке | 518 | 518 |
| Компаний с товарными данными | 139 | 139 |
| Компаний с хотя бы одной категорией | 65 | 68 |
| Товарных строк | 902 | 902 |
| Товаров с соответствием | 197 | 248 |
| Покрытие товарных строк | 21.8% | 27.5% |

Найдено 102 ранее не распознанных товарных строк. У 51 строк прежние совпадения больше не выдаются после ужесточения правил. Такие снятия не означают автоматически, что все прежние назначения были ошибочными: консервативные проверки также могут снижать полноту.

Сравнение относится к совокупности изменений словаря и алгоритма. Это покрытие, **не точность**: независимой экспертной разметки всего Excel нет. Остались 654 товарных строк без решения. Причиной может быть отсутствие категории, синонима или недостаточность названия товара.

## Проверки

- 70 положительных и отрицательных регрессионных примеров в `internal/categorize/testdata/regression.json`: все прошли. Это контроль известных случаев, не независимый тест качества.
- Проверено соответствие справочника и словаря один к одному, отсутствие неизвестных названий и обязательная причина отключения.
- `go test -race ./...`, `go vet ./...`, `go build ./...`: успешно.
- Исправлены случаи «метры из длины удлинителя», «угол → уголь», «монитор УФ → компьютерный монитор», «оборудование» без вида товара, назначение отсутствующих деталей после «без».

## Повторный запуск

```bash
go run ./cmd/categorize --limit 518 --out outputs/category-full
go test ./internal/categorize
```

Подробные решения и товары-основания находятся в `report.md` и `report.json` в этом каталоге.
